# Звіт з лабораторної роботи №2

**Тема:** Розділені різниці. Інтерполяційні многочлени Ньютона та факторіальних многочленів.
**Мета:** Вивчити методи обчислення розділених різниць довільного порядку і вивчити метод інтерполяції з використанням інтерполяційних многочленів Ньютона та факторіальних многочленів для довільної конфігурації вузлів.

## 1. Теоретичні відомості

Інтерполяційний многочлен Ньютона базується на використанні **розділених різниць**. Для заданого набору вузлів $(x_0, y_0), (x_1, y_1), \dots, (x_n, y_n)$ розділені різниці обчислюються рекурсивно:

* Нульового порядку: $f(x_i) = y_i$

* Першого порядку: $f(x_i, x_{i+1}) = \frac{f(x_{i+1}) - f(x_i)}{x_{i+1} - x_i}$

* $k$-го порядку: $f(x_i, \dots, x_{i+k}) = \frac{f(x_{i+1}, \dots, x_{i+k}) - f(x_i, \dots, x_{i+k-1})}{x_{i+k} - x_i}$

**Многочлен Ньютона** для інтерполяції вперед має вигляд:

$$
N_n(x) = f(x_0) + (x-x_0)f(x_0, x_1) + \dots + (x-x_0)\dots(x-x_{n-1})f(x_0, \dots, x_n)
$$


Головна перевага цієї форми — можливість додавати нові вузли без перерахунку вже знайдених коефіцієнтів (на відміну від многочлена Лагранжа).

Для **рівновіддалених вузлів** зручніше використовувати скінченні різниці ($\Delta f(x)$) та **факторіальні многочлени** $x^{(n)} = x(x-1)\dots(x-n+1)$. Розклад функції за факторіальними многочленами є дискретним аналогом ряду Тейлора.

## 2. Хід роботи та аналіз результатів (Варіант 1)

**Завдання:** Прогнозування часу виконання алгоритму залежно від розміру вхідних даних ($n$).
Було зчитано набір даних із CSV файлу:

* $n$: \[1000, 2000, 4000, 8000, 16000\]

* $t$: \[3, 5, 11, 28, 85\]

1. **Побудова моделі Ньютона:** Було програмно реалізовано алгоритм побудови матриці розділених різниць та обчислення полінома.

2. **Прогноз:** Для заданого розміру $n=6000$ обчислено прогнозований час виконання. Результат інтерполяції Ньютона склав $\approx 18.27$ мс.

3. **Факторіальні многочлени:** Оскільки оригінальна сітка вузлів $n$ є геометричною прогресією (не рівномірна), пряме застосування формули скінченних різниць є некоректним. Тому для демонстрації було створено штучну рівномірну сітку $x_{uniform} \in [2000, 8000]$ з кроком $h=2000$, обчислено проміжні значення та застосовано факторіальну формулу. Обидва методи дали ідентичний результат для $n=6000$.

## 3. Дослідницька частина (Ефект Рунге)

Згідно з інструкцією, було досліджено вплив кількості вузлів на точність інтерполяції за допомогою класичної функції Рунге $f(x) = \frac{1}{1+25x^2}$ на відрізку $[-1, 1]$.

* **5 вузлів:** Многочлен грубо наближає функцію. Максимальна похибка $\approx 0.43$.

* **10 вузлів:** Точність у центрі відрізка покращується, але на краях відрізка (біля -1 та 1) з'являються помітні осциляції (відхилення). Похибка зростає до $\approx 1.91$.

* **20 вузлів:** Осциляції на краях стають катастрофічними. Многочлен різко коливається, а максимальна похибка сягає величезних значень ($\approx 59.5$).

**Висновок до дослідження:** Збільшення кількості рівномірно розподілених вузлів при глобальній поліноміальній інтерполяції (Ньютон, Лагранж) для певних функцій призводить не до зменшення, а до різкого зростання похибки на краях відрізка. Це явище називається **ефектом Рунге**. Саме тому для великої кількості точок доцільніше використовувати локальну інтерполяцію (наприклад, кубічні сплайни з Лабораторної №1).

## 4. Відповіді на контрольні питання

**1. Що називається інтерполяцією? У чому її відмінність від екстраполяції?**
Інтерполяція — це знаходження проміжних значень функції всередині відрізка, на якому задані вузли. Екстраполяція — це прогнозування значень функції за межами цього відрізка (наприклад, прогноз у майбутнє).

**2. У яких випадках застосовується інтерполяційний многочлен?**
Застосовується для відновлення функції за її дискретними значеннями (таблицями), для чисельного диференціювання та інтегрування, а також в комп'ютерній графіці для побудови плавних кривих через малу кількість опорних точок.

**3. Що таке вузли інтерполяції?**
Це набір фіксованих точок $x_0, x_1, \dots, x_n$, у яких відомі точні значення шуканої функції $y_0, y_1, \dots, y_n$.

**4. Яка максимальна степінь інтерполяційного многочлена при** $n + 1$ **вузлах?**
Максимальна степінь многочлена дорівнює $n$.

**5. У чому полягає метод Ньютона?**
Метод Ньютона полягає в побудові інтерполяційного многочлена у вигляді суми доданків, де кожен наступний доданок містить добуток різниць $(x-x_i)$ та коефіцієнт у вигляді розділеної різниці відповідного порядку.

**6. Що таке розділена різниця нульового, першого та вищих порядків?**
Нульового порядку — це саме значення функції у вузлі $f(x_i)$. Першого порядку — це відношення різниці значень функції до різниці аргументів $\frac{f(x_{i+1})-f(x_i)}{x_{i+1}-x_i}$. Вищих порядків — це рекурсивне відношення різниць попереднього порядку.

**7. Як формується таблиця розділених різниць?**
Таблиця формується по стовпцях. Перший стовпець — вузли, другий — значення функції (0-й порядок). Кожен наступний елемент у новому стовпці обчислюється як різниця двох сусідніх елементів попереднього стовпця, поділена на різницю відповідних крайніх вузлів.

**8. Запишіть загальний вигляд інтерполяційного многочлена Ньютона.**
$P_n(x) = f(x_0) + f(x_0, x_1)(x-x_0) + f(x_0, x_1, x_2)(x-x_0)(x-x_1) + \dots + f(x_0, \dots, x_n)(x-x_0)\dots(x-x_{n-1})$

**9. Які переваги має форма Ньютона порівняно з формою Лагранжа?**
Форма Ньютона обчислювально ефективніша при зміні кількості вузлів. Також вона є більш стабільною для обчислень, якщо вузли додаються послідовно.

**10. Чому форма Ньютона зручна при додаванні нових вузлів?**
При додаванні нового вузла $x_{n+1}$ не потрібно перераховувати весь многочлен заново. Достатньо лише обчислити нові розділені різниці та додати до існуючого многочлена $P_n(x)$ один новий доданок.

**11. Які основні етапи обчислення факторіальних многочленів?**
Перевірка вузлів на рівномірність (крок $h=const$). Обчислення таблиці скінченних (а не розділених) різниць $\Delta^k y$. Застосування формули факторіального розкладу (аналог ряду Тейлора) з використанням параметра $t = \frac{x-x_0}{h}$.

**12. У чому різниця між факторіальними многочленами та многочленами Ньютона?**
Многочлен Ньютона (через розділені різниці) є універсальним і працює для довільного розміщення вузлів. Факторіальні многочлени (через скінченні різниці) є окремим, більш простим та швидким випадком многочлена Ньютона, але вони вимагають строго рівномірної сітки (рівновіддалених вузлів).
